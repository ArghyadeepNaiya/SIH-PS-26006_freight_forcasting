Forecast honesty panel

Skill score is 1 − (model error / naive error), where naive means assuming tomorrow's rate equals today's. Positive means the model beats doing nothing. Zero or below means it does not, and we say so rather than hide it.

    Every value below carries a source citation. Values marked ASSUMPTION are unverified placeholders and must be confirmed with the port authority before this system is used for a real decision.
    Two live inputs feed the ranking on the Decision Console. The first is what each port operator declares through their own password protected dashboard, about free area, availability, accepted vessel classes and cargo demand. The second is the weather forecast at each quay and each approach anchorage. Everything an operator declares is dated and attributed. It is not a published port authority figure, and this page never pretends otherwise.
